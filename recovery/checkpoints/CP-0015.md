## Completed work (OPS 5.5 audit P2)
- **Transcription model option:** binding config `transcription_model` → `S2SSessionConfig.extra` → OpenAI `audio.input.transcription.model` (default `whisper-1`). `comp_s2s_openai_v1` uses `gpt-4o-transcribe`; `comp_s2s_openai_whisper_v1` is the whisper-1 baseline.
- **F-09 Silero honesty + real Silero:** session facts / session detail report the detector that *runs* (`turn_detector`), health reports `silero_model_available`; `scripts/fetch_models.sh` (MIT Silero v5 ONNX, untracked `models/`), `vad` extra = onnxruntime. **Live-found defect:** the ONNX wrapper omitted the v5 64-sample context → clear speech scored ≤0.1 (0 turns heard). Fixed; speech now 1.0, silence 0.009.
- **Live-found Core defect (barge-in):** the client pump processed messages serially, so the client's `playout_stopped` ack sat behind the processor awaiting it → *every* audio barge-in was forced at 300 ms (`playout_stop_timeout`). A reader task now signals the ack directly; processing order unchanged.
- **Live-found Core defect (close):** close() triggered from a pump could be cancelled by run()'s pump teardown → no record, `AssertionError` surfaced as `provider_failure`. close() is now single-flight + shielded.
- **Harness:** `scripts/latency_table.py` (EOT→first audio, barge-in t1→t2/t3/t4, forced count, split turns, CER vs synthetic phrase); voice trace records user transcripts + session facts and now **fails** when a clip is not heard, the agent never spoke, or the session errored / produced no outcome (the P2 zero-turn session previously passed).
